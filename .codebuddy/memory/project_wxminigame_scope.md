`wxminigame` / `wxminigame-v2` 分支上**只做平台适配，不新增任何东西**：不开新玩法、不加实体/物品/配方，
也不加主线没有的限制（例如自定义 Boss、世界数量上限、交互捷径）。

允许的改动只有平台层：触摸输入、性能与视距、Worker、文件存档、分辨率与安全区；
触摸导致 UI 必须重排时可以重排，但**玩法语义不能变**。

**Why:** 小程序版是主线 Web 版的移植，不是第二套产品——加了主线没有的东西，两边就再也对不齐，验证成本翻倍。
**How to apply:** 每条任务先审计主线 Web 是否存在对应功能/数值/流程，不存在就回"不做"并说明理由。
细节以该分支里的 `WXMINIGAME*.md` 为准（`WXMINIGAME_SYNC.md` 是同步台账），不要在这里抄。
