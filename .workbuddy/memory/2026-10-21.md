## 小游戏预览打不开的排查（53704 → 3899）

- 现象：给了 `http://localhost:53704`，用户打不开。`lsof` 确认该端口**已无监听**，curl 返回 502。
- 两个坑：
  1. `run_game` 每次重启都**换随机端口**（53704 → 64004 → …）；
  2. helper 只监听 **IPv6 `[::1]`**，`http://127.0.0.1:PORT` 直接 502，只有 `localhost` / `[::1]` 能通。
- 解法：新增 `tools/minigame/preview-proxy.mjs`（`npm run preview:minigame`），
  固定 3899 双栈反代到 helper 当前端口，每 10s 复查上游、换端口自动切换。
  localhost / 127.0.0.1 / [::1] 三个地址均验证 200。
- 顺带修 e2e：**不要 `page.reload()`**——helper 一个页面只托管一次游戏实例，
  二次加载会 500（`useGameFrame: Failed to fetch game.json`），游戏停在 wx-compat 之后、零条 `[V2]`。
- 另一坑：连续开太多 Chromium 实例会耗尽 WebGL 上下文，
  报 `THREE.WebGLRenderer: Cannot read properties of null (reading 'injected')`，需重启 helper。
- 又撞车：远端 `ca33f5d5`（产品优先进光标）已合并，无冲突。
