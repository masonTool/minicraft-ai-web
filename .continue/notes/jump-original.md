## 11. 测量方法与误差

- 工具：`.tmp/imgprobe.mjs`（`sips -s format png` 转码后用 Node `zlib` 手动解 PNG 过滤链，
  支持 `info` / `mode` / `bbox` / `dark` / `scanrow` / `scancol` / `grid`）。`.tmp/` 已 gitignore。
- 参考图是**攻略文里的二次压缩 JPEG**，块面内部颜色稳定（误差 <3/255），但边缘有 1~3px 的发虚，
  所以"边长""菱形高宽比"这类**边界**测量误差按 ±3% 计。
- 最干净的一次测量是 03 灰块（无遮挡、纯色）：顶面 bbox 249×130 → 高宽比 0.522。
  方块边缘的圆角会让 bbox 略小（约 4px），修正后 0.51~0.54，仍落在 30°±2°。
- 02 里"黄块→橙块"的中心距测量（238.7 屏幕像素）自带 ±20px 误差（顶面被小人遮挡一角），
  所以只写成区间 1.15~1.9 边长，实际取值由队列 `[跳5]` 的 `gapMin`/`gapMax` 平衡测试决定。
- 05 被攻略文的红色标注框/箭头覆盖，**红色不从 05 取**（魔方的红取自 06）。
