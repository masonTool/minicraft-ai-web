# 真机验收清单（canvas 自绘界面）

> 为什么单独一份：离线能验的（断言、截图、空白检测）都验完了，剩下的每一条都只在
> **有 `core.bin` 的真机/模拟器**上才成立。这个文件的作用是让那一次上机**不遗漏、可打勾**。
>
> 用法：在能进世界的环境里逐条走，每条后面填 `✅` / `❌ + 现象`。发现问题直接开一条 TASKS。
>
> 环境：`npm run dev`（或部署后的地址）+ 下面每条给的 URL 参数。

## A. 自绘背包接管（`?ui2d=1&ui2dinv=1`）

| # | 动作 | 期望 | 结果 |
| --- | --- | --- | --- |
| A1 | 进世界 → 打开背包 | 面板整块由 canvas 画（开 `?ui2dtint=1` 应整片黄，**没有 DOM 残影**） | |
| A2 | 左键点第 1 格 | 整叠拿在手上，跟着指针走 | |
| A3 | 左键点空格 | 整叠放下、手上清空 | |
| A4 | 右键点有货的格子 | 取一半（向上取整） | |
| A5 | 右键点空格（手上有一叠） | 放**一个** | |
| A6 | 左键按住拖过 3 个空格再松手 | 均分（余数给前面的格子） | |
| A7 | 右键按住拖过 2 格 | 每格放 1 个 | |
| A8 | 400ms 内双击同一格 | 收集同类凑满（凑不到就快速移动） | |
| A9 | 悬停任意格 | 出现格位高亮（白框）——不是 DOM 的 `:hover` | |
| A10 | 悬停有名字的物品 | 紫底提示框（名字 / 数量 / 耐久条），靠右下、贴边会翻边 | |
| A11 | 数字键 1–9（悬停某格时） | 该格与对应快捷栏格**交换** | |
| A12 | Shift + 左键 | 快速移动到另一区（先并堆再占空格） | |
| A13 | 拖出面板外松手 | 丢出（地上出现掉落物） | |
| A14 | 点面板右上角 × | 背包关闭（走 `forwardClickAt` 转发） | |
| A15 | 关掉背包再开 | 状态干净（没有残留的手持叠、没有卡住的高亮） | |

| # | 动作 | 期望 | 结果 |
| --- | --- | --- | --- |
| B1 | 点一下格子 | 整叠拿起（不是长按语义） | |

| B5 | 手指贴着创造栏上下滑 | 列表**跟手**滚动，松手有惯性、滚动条跟着动 | |
| B6 | 拖滚动条拇指 | 能拖动（不是只有画上去） | |

## E. 创造栏（`?ui2d=1&ui2dinv=1`，创造模式）

| # | 动作 | 期望 | 结果 |
| --- | --- | --- | --- |
| E1 | 打开创造栏 | 12 列 × 34px 网格 + 5 个页签 + 搜索框 + 翻页提示 | |
| E2 | 点页签 | 只显示该页签的物品，页数随之变化 | |
| E3 | 搜"石" / 搜 "stone" | 都能搜到（三个别名：本地化名、英文 label、id） | |
| E4 | 点一件物品 | 拿到**一整叠**（64），而栏里那一件**不减少** | |
| E5 | 翻到第 2 页再搜一个只有几件结果的词 | 页码自动夹回，不出现空白页 | |

## F. 暂停弹窗（`?ui2d=1`）

| # | 动作 | 期望 | 结果 |
| --- | --- | --- | --- |
| F1 | 游戏里按 Esc | 暂停面板由 canvas 画；背后的 HUD 让位（不重影） | |
| F2 | ↓ 一下再 Enter | 进设置页，设置项都能读出来、能改 | |
| F3 | Esc | 退回暂停菜单 | |
| F4 | Esc 再关 | 面板关闭，**HUD 与游戏恢复**（不残留隐藏状态） | |

> F 段就是 `npm run check:pause` 那 8 条断言的真人版；脚本能跑的环境里可以先跑脚本再抽查。

## G. 已知的"没做/不打算做"

- 酿造台的**泡泡**判定（DOM 里也只是装饰）；
- 视角面（`view` 那颗按钮换的是相机朝向，不是 UI）；
- 镜像模式下 recipe 书的**滚动条拖动**在自绘接管时才生效，普通镜像仍是 DOM 滚动。
