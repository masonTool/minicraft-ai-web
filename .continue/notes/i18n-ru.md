## 俄语的三处特殊处理

1. **复数（4 个 CLDR 类别）**：`one / few / many / other`。
   规则：1、21、31 → one（`блок`）；2~4、22~24 → few（`блока`）；0、5~20、25~30 → many（`блоков`）。
   `locales/ru/plural.ts` 登记了 **6 条**真正会读错的键（`statistics.blocks` / 四条 `buildtools.*.done` / `station.brewLeft`），
   其余键由 `tn()` 回落到 `t(key)` —— 缩写（`{count} мин`）不随数变格，不必登记。
   ⚠️ **动词也要跟着变**：`Выделен 1 блок` / `Выделено 2 блока`，所以四条 buildtools 的三种形式是整句写出来的，不是拼名词。
2. **西里尔字形**：canvas 上的告示牌与名字牌用系统字体栈
   （`"Noto Sans SC", "PingFang SC", "Microsoft YaHei", system-ui, sans-serif`）。
   中文字体通常**没有西里尔字形**，会落到 `system-ui` / `sans-serif` —— 各大桌面与移动系统都带西里尔，
   所以能显示；但**字体度量与中文不同**，告示牌上四行的换行位置会变，属已知差异。
3. **词序**：俄语的"在 X 里制作 Y"是 `Y делается в X`，与中文同序（`{item} 在 {label} 里制作` → 反过来）。
   这类句子一律整句进表（`station.needOtherStation`），不做拼接。

## 加一种语言的完整步骤（留给 pt / fr 照抄）

1. 复制 `locales/zh/`（或 `de/`、`ru/`）到 `locales/<code>/`，逐组改值 —— 键**不要动**；
   每个分组文件都用 `satisfies Pick<Messages, keyof typeof zhXxx>` 收口，漏一条编译不过。
2. `locales/<code>/index.ts` 合成并 `satisfies Messages`。
3. 若这种语言有复数变格，写 `locales/<code>/plural.ts`，并在 `I18n.ts` 的 `PLURAL_TABLES` 里登记
   （⚠️ 复数表是**静态导入**的：`tn()` 必须同步拿到它，而它只有几行）。
4. `I18n.ts` 的 `LOADERS` 加一行：`<code>: () => import('./locales/<code>/index.ts'),`。
5. `public/manifest.<code>.webmanifest`（目前只有 zh / en；其余语言回落英文那份）。
6. `npm run audit:i18n` 看「已翻 / 与英文写法相同」；`npm run test:i18n` 有 30+ 条语言相关断言兜底。
7. **改语言清单相关的断言**：`test:i18n` 里"没装表的语言"的例子要用**还没有表也没有加载器**的那种
   （现在只剩 `pt` / `fr`）—— 每加一种真实语言就要把这个例子往后挪一格，否则那几条断言会假红。

## 俄语物品名的第四个特殊处理：**名词短语拼不出来时，用"括号归属"式**

俄语的形容词要与名词的性、数、格一致（`Полированный гранит` 阳性、`Полированная плита` 阴性），
而模板对 16 色 × 10 族只放一个 `{color}` —— 平坦模板必然变错。这四类因此改成括号归属：

| 族 | 俄语写法 | 为什么 |
| --- | --- | --- |
| 颜色 10 族 | `Шерсть (Белый)` / `Кровать (Оранжевый)` | 颜色词只有阳性形式，直接前置会与名词性冲突 |
| 工具 30 件 | `Кирка (алмаз)` | 材质形容词也要变格（`алмазная кирка` / `алмазный топор`） |
| 盔甲 24 件 | `Нагрудник (незерит)` | 同上，且 `поножи` / `сапоги` 只有复数 |
| 台阶/楼梯/墙 | `Плита (Камень)` / `Ступени (Дубовые доски)` | 基名是名词短语，加 `плита` 需要形容词化 |

**这两类反而能自然拼**（词干同构，加词尾就对）：
- 木材 8 形态：词干 `Дубов` + 词尾 → `Дубовое бревно` / `Дубовые доски` / `Дубовый забор`（性数一致全部命中）
- 珊瑚 3 形态：`Трубчатый коралловый блок` / `Трубчатый коралл` / `Трубчатый веер`（五个珊瑚词都是阳性硬词干）

⚠️ 已知的外观瑕疵：括号里的词首字母是大写（`Плита (Камень)`），因为构件本身要给单独使用时的句首形态。
要修就得在渲染时做"括号内小写"，那是 i18n 层之外的事，暂不做。
