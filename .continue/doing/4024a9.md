- [x] [P2-1a] 名字表改**惰性求值** + 染料族键化：`itemNames.ts` 的 `NAMES`（id → 中文字符串）改成 `id → () => string`，`translateName()` 调用时才求值；新建 `locales/{zh,en}/item.ts` 放颜色 16 条与染料族 10 个模板（`item.tpl.<family>`），该族 160 条名字由 `tp()` 拼装 → 全量 `itemLabel()` / `blockLabel()` 改造前后 **diff 零差异**，`test:i18n` + `test:unit` 全绿
  - 做了什么：`itemNames.ts` 的 `NAMES` 从 `id → 中文字符串` 改成 `id → string | (() => string)`，`translateName()` 在**取值那一刻**才求值；新增 `locales/{zh,en}/item.ts`（**29 条键**：16 个颜色 + 10 个染料族模板 `item.dye` / `item.wool` / … + 3 个无色底座），接入两个 `index.ts`；染料族 **160 条**名字改由 `tp('item.dye', { color })` 拼装

  - 为什么用模板而不是 800 条平铺：物品名几乎都是"颜色 + 名词"或"材质 + 名词"。平铺成 800 条 → 6 种语言各写 800 条；模板放表里、拼接留代码里 → 加语言只翻**构件**，而且德语语序（`{color} Wolle`）、俄语变格都能各自给
