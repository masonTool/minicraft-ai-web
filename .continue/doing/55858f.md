- [x] 蓄力/进食/举盾不再被判成"破坏"（视角可转、无长按震动）：`web/src/ui/TouchControls.ts` + `web/src/main.ts` → `npm run test:ui`
  - 做了什么：`TouchControls` 新增 `setHoldMeansUse()` 与 `longHeld`：越过 400ms 阈值时若 `holdMeansUse` 只记 `longHeld`，不置 `breaking`、不回调 `onBreakStart`；抬手时 `longHeld` 的手势不派发 `onTap`。主程序新增 `holdMeansUse`（弓/弩/望远镜 + 食物/药水 + 盾），在 `refreshHotbar` 落一次。
  - 为什么：根因是 `pointermove` 里 `if (this.lookDragged && !this.breaking)`——长按 400ms 把 `breaking` 置真之后**视角就再也拖不动**（用户："这个时候我是没办法调整视角的"），而 Android 又给了一次长按触觉反馈（"手机会震一下"）。两个症状同一个原因。
  - 验证：`npm run test:ui` 1248 通过；`npm run check:fast` 全绿。
