## D43 · 用"像素统计"当 canvas 页面的门禁，而不是信任截图
- 决定：新增 `npm run check:ui2d-visual`（`tools/ui2d-visual-check.mjs`）：对 7 个预览页读**面积最大那块 canvas** 的像素，断言非透明占比 ≥ 每页阈值、颜色种类 ≥ 3、且无 `pageerror`；没浏览器时跳过。
- 为什么：今天两次"截图成功、页面全空"——一次是内联 `<script>` 里写了 TS 语法（浏览器直接报错，脚本没跑），一次是截图抓太早。两者都产出一张"天空+草地"的图，**看着就像还没画**，而 `npm run check` 不跑浏览器、覆盖不到。
- 影响：① 必须挑最大 canvas（背包页有几十块 36×36 图标，`querySelector` 会拿到图标并"健康通过"）；② 阈值按页给（触控页只有摇杆和按钮，占比天然低）；③ 这道门禁**不能**替代真机验收 —— 它只回答"画出来东西了吗"，不回答"画得对不对"。
