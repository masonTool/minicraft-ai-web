## D55 · 侧栏进布局；面板高度必须取"玩家网格"与"侧栏"的较大值
- 决定：`layoutInventoryPanel({ side: { count, offhandGap? } })` 在面板右侧竖排一列（盔甲从上到下、副手隔 6px）；槽位顺序延长为 **extra(+result) → side → main → hotbar**；面板 `h = title + extraRow + max(playerHeight, sideHeight) + padding`；`F` 键与副手交换。
- 为什么：① 侧栏是布局层最后一个缺口，做完之后"19 种工作站 + 生存背包 + 创造栏"都可以用同一套函数表达；② 高度不取较大值就会**把副手画到面板外面**（第一版实测，截图里一眼可见）——这类"漏算一列高度"的错在纯逻辑断言里很容易漏，所以补了"副手在面板内"的断言。
- 影响：① 槽位顺序又长了一节，改顺序要同时改所有调用方（`SlotAccess` 下标就是索引）；② **穿戴规则仍是游戏逻辑**，现在任何物品都能塞进盔甲格 —— 已记在 M37 的剩余项里。
