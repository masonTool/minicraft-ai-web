## D21 · 纯文字面板走"原位重画"，不重排版
- 决定：`ui2d/textPanel.ts` 读 DOM 里直接带文字的叶子元素（矩形 + 文本 + `getComputedStyle` 的颜色/字号/字重/对齐/阴影），连同"有色底"的元素一起按原位画；不自己算行高、不做两列布局。
- 为什么：这一块与前面所有块不同——前面（快捷栏/状态栏/设置表单）**版式是固定的**，自己排版还能保证与 CSS 一致；而 F3 是拼出来的多行字符串、计分板是 flex 两列、颜色字号还跟着夜间/断点变。重排一遍等于把三样规则各抄一份，且**没有任何断言能发现抄错**（错的样子只是"看着有点歪"）。
- 影响：多了一次 `getComputedStyle` 的代价，用"文字内容 + 视口"签名挡在门后（F3 默认关，常态零成本）。退得回去：这三行字本来就没有交互，最坏就是回退成 DOM 显示。
