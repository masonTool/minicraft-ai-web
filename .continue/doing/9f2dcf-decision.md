## D52 · "拿在手上那一叠"只能有一份状态；先只读合流，接管输入时再写回
- 决定：`InventoryPanelHost` 接受 `externalCursor: { get, set? }`，入口拉、`render()` 推（没给 set 就只读）；`InventoryScreen` 开放只读 `heldStack`；游戏侧叠加层只传 `get`。
- 为什么：DOM 与自绘各存一份 held，症状很具体 —— **拖动时屏幕上出现两叠**。而这一阶段自绘面板还不吃输入，贸然写回会与 DOM 的分配逻辑打架（谁先谁后没有定义）。只读合流既消除了"两叠"，又不动现有输入链路。
- 影响：① 接管输入那一批必须同时加 `set` 并让 DOM 面板停止渲染，否则又回到两份状态；② `heldStack` 是 getter 而不是字段，避免外部直接改私有状态绕过 `#inv-held` 的更新逻辑。
