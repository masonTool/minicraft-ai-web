## 1. 各界面逐张

### ① 物品栏（左轨底部"箱子"）＝ `data-pocket-tab=crafting`

- 左半区：27 格 3×9（**我的物品**）
- 右半区：2×2 合成 + `→` + 产物槽，左上角小字「合成」
- 右轨「合成」高亮

### ② 右轨「合成」＝ 同上（`crafting`）

与 ① 完全一致 —— **它们本来就是同一个页签**，只是入口有两个。

### ③ 右轨「盔甲」＝ `data-pocket-tab=armor`

- 左半区：27 格 3×9
- 右半区：**竖排 5 格**，每格**左侧有文字标签**「头 / 胸 / 腿 / 靴 / 副手」
- 再右边：**3D 玩家模型预览**（黑色背景，能拖转）
- 顶部有「盔甲」小标题

### ④ 左轨 5 颗分类（生存模式）＝ 配方书

- 左半区：**配方卡列表**（不是物品网格）—— 列出"用背包里的材料能做出什么"
- 底部一行：`分类：建筑 · 可合成 0`（没材料时是 0）
- 右半区：仍是 2×2 合成 + 产物

### ⑤ 左轨 5 颗分类（创造模式）＝ 物品网格

- 左半区：**物品网格**（每格一整组 64）+ **顶部搜索框**「搜索物品…」
- 右半区：2×2 合成 + 产物
- 左轨当前分类高亮

> ⚠️ 同一个按钮在生存/创造下内容不同：
> **生存 = 配方卡（能做什么）**、**创造 = 物品网格（有什么）**。

### ⑥ 右轨「成就」

打开独立的成就面板（整块盖住背包），顶部 5 个筛选页签
（全部 / 我的世界 / 下界 / 未地 / 冒險 之类），下面是成就行。
**这不是背包的一部分**，是另一个界面，v2 可以不做（v2 没有成就系统）。

## 2. v2 与外部端的差距（本次要补的）

| 项 | Web | v2 现状 | 处理 |
|---|---|---|---|
| 右轨三颗 | 成就 / 合成 / 盔甲 | 创造 / 合成 / 盔甲 ❌ | **改成 成就 / 合成 / 盔甲** |
| 左轨图标 | 物品贴图 | 中文单字 | 用 `drawBlockIcon` 画真图标 |
| 盔甲页 | 竖排 + **文字标签** + **3D 预览** | 只有竖排 5 格 | 补标签 + 预览 |
| 分类页（生存） | 配方卡列表 + 「分类：X · 可合成 N」 | 物品网格 | 补配方卡模式 |
| 分类页（创造） | 物品网格 + **搜索框** | 物品网格 + 搜索按钮 | 对齐搜索框 |
| 2×2 合成区 | 左上角小字「合成」 | 无 | 补 |
