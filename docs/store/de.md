## Volltext — 1916 Zeichen

```
Eine von Grund auf in TypeScript und WebGL2 geschriebene Block-Sandbox, spielbar im Handy- und Desktop-Browser.

■ Welt
Unendliches Gelände, Höhlen, Erzadern und Biome: Ebene, Wald, Wüste, Schneetaiga, Dschungel, Sumpf, tiefer Ozean… Berge und Meeresböden entstehen aus echten Höhendaten, und am Rand steht keine Wand.
Über 20 erkundbare Bauwerke: Dörfer, verlassene Minen, Festungen, Verliese, Ozeanmonumente, Waldanwesen, Bastionsruinen, Endstädte. Gleicher Seed, gleiche Welt.

■ Spiel
· Überleben: Hunger, Leben, Drops, Respawn-Punkte und vier Schwierigkeiten — auf Friedlich erscheinen keine feindlichen Kreaturen
· Kreativ: Fliegen, unendlich Blöcke, sofortiges Abbauen, dazu ein komplettes Bauwerkzeug (Auswahl / Füllen / Kopieren / Einsetzen / Spiegeln / Rückgängig / Vorlagen)
· Über 200 Rezepte: Werkbank, Ofen, Räucherofen, Schmelzofen, Lagerfeuer, Steinsäge, Schmiedetisch, Braustand, Webstuhl, Kartentisch, Amboss, Schleifstein, Zaubertisch
· Über 70 Kreaturen, inklusive Dorfbewohner-Handel, Zähmen und Reiten
· 36 Befehle mit grafischer Hilfe (Parameter anklicken, direkt in den Chat übernehmen)
· Minispiele und eine Einführung beim ersten Start

■ Bedienung
Zwei Steuerungen — Touch und Tastatur/Maus — Querformat-Vollbild, einstellbare Knopfgröße und Empfindlichkeit, Doppeltippen zum Schleichen, Halten zum Abbauen.
Oberfläche in sechs Sprachen: 简体中文, English, Deutsch, Русский, Français, Português (Brasil).

■ Über das Projekt
Dies ist ein unoffizielles Fan-Remake, steht in keiner Verbindung zu Mojang oder Microsoft und enthält keine offiziellen Inhalte.
Alle Texturen und Klänge entstehen zur Laufzeit im Code. Spielstände liegen auf dem eigenen Gerät (lokaler Browserspeicher) und werden nie hochgeladen.

■ Hinweise
· Der erste Start erzeugt eine Welt und kann auf schwachen Geräten einige Sekunden dauern
· Querformat empfohlen; über „Zum Startbildschirm hinzufügen" startet es im Vollbild
```
