## 长描述 — 707 字符

```
一个用 TypeScript 与 WebGL2 从零写起的方块沙盒，在手机与桌面浏览器里都能玩。

■ 世界
无限地形、洞穴、矿脉与群系：平原、森林、沙漠、雪原、丛林、沼泽、深海…… 山体与海底按真实高度生成，走到哪都没有边界墙。
创造了 20 多个可探索结构：村庄、废弃矿井、要塞、地牢、海底神殿、林地府邸、堡垒遗迹、末地城。种子相同的世界地形也相同。

■ 玩法
· 生存：饥饿、生命、掉落物、重生点、难度四档，和平难度下不会刷出敌对生物
· 创造：飞行、无限方块、秒破，另有一整套建造工具（选区 / 填充 / 复制 / 粘贴 / 镜像 / 撤销 / 建筑模板）
· 合成 200+ 配方：工作台、熔炉、烟熏炉、高炉、营火、切石机、锻造台、酿造台、织布机、制图台、铁砧、砂轮、附魔台
· 生物 70+ 种，含村民交易、驯服与骑乘
· 命令 36 条，带图形化帮助面板（可点选参数、直接填入聊天框）
· 小游戏与新手引导，第一次进来不会不知道做什么

■ 手感
触屏与键鼠两套操作，横屏全屏、可自定义按钮大小与灵敏度；支持手柄式摇杆、双击潜行、长按挖掘。
界面六种语言：简体中文、English、Deutsch、Русский、Français、Português (Brasil)。

■ 关于
独立开发的方块沙盒，所有素材都由本项目自己生成。
所有贴图与音效都在运行时由代码生成，存档保存在你自己的设备上（浏览器本地存储），不会上传到任何服务器。

■ 说明
· 首次进入需要生成世界，低端设备上可能等待数秒
· 建议横屏游玩，可"添加到主屏幕"后全屏启动
```
