# Web 版（外部端）背包结构分析 · 用于重构 v2

> 数据来源：`http://127.0.0.1:5199` 真机截图 + 运行时 DOM 量测（1280×720）+ `index.html` 的
> `.inv-*` CSS。**不是照源码猜的**，是量出来的。

关键数字：

| 项 | 值 |
|---|---|
| 面板 | 背景 `#c6c6c6`（`rgb(198,198,198)`），**直角**（`border-radius: 0`），3px 斜角边框（左上亮右下暗） |
| 槽位 | 42×42（主背包 40×40，快捷栏 44×44），2px 斜角边框，直角 |
| 底色 | 槽位 `#8b8b8b` 系（`--slot-bg`），选中 = **白底 + 深框**（像相框） |
| 文字 | 深灰 `#3a3a3a`（浅灰面板上用**深字**，与 v2 现在的深底白字相反） |
| 左轨 | 配方书 5 颗 36×36 **竖排**，gap 2；底部一颗"物品栏" |
| 右轨 | 3 颗 36×36 竖排，gap 4（合成 / 盔甲 / …） |
| 快捷栏 | **面板之外**，屏幕底部独立 dock |

## 2. 左轨 5 颗 = 配方书的 5 个分类

不是"物品/创造/配方"三个页签！v2 现在是三个大按钮，Web 版是：

```
[🔍]  ← 全部（放大镜）
[🪨]  ← 建筑
[⚔]  ← 装备
[🍎]  ← 物品
[🌿]  ← 自然
  ↓ (空隙)
[🎒]  ← 物品栏（回到普通背包）
```

对应代码：`RECIPE_BOOK_TABS_POCKET`（`all` / `building` / `equipment` / `items` / `nature`），
与 v2 已有的 `CREATIVE_CATEGORIES` 是**同一套 key**（`all/building/equipment/items/nature`）。

> ⚠️ 这就是重构的抓手：v2 已经有 `creativeTabFor()` 这套分类，只是现在被塞在"创造"页签里。
> Web 版是**左轨直接选分类**，选中后面板内容切换，不需要先点"创造"再点分类。

## 3. 右轨 3 颗 = 面板模式

| 位置 | 作用 |
|---|---|
| 上（`--inv-rail-action`） | 切"创造物品 / 生存背包" |
| 中（active） | 合成 |
| 下 | 盔甲 |

## 4. 各页签的 body 内容（由 `data-pocket-tab` 驱动）

| `data-pocket-tab` | body 内容 |
|---|---|
| `crafting`（默认） | 2×2 合成 + 箭头 + 产物；玩家 27 格在左列 |
| `armor` | 27 格在左 + 右侧竖排盔甲 4 + 副手 |
| `inventory` | **只有** 3×9 主背包（快捷栏在 dock） |
| 工作台 | `workbench-ui`：3×3 合成在**上**，玩家背包在下（纵向） |
| 创造 | `creative-ui`：分类在左轨，面板内只有搜索 + 网格 + 销毁 |

## 5. 与 v2 现状的差距（这就是"一脸蒙"的来源）

| 维度 | Web 版 | v2 现状 |
|---|---|---|
| 配色 | 浅灰面板 `#c6c6c6` + 深灰字 | 深蓝黑 `rgba(16,22,28,.97)` + 白字 |
| 形状 | 全直角 + 斜角边框 | 12px 圆角 |
| 左栏 | 配方书 5 分类**图标**竖排 | 三个大文字按钮（物品/创造/配方）|
| 快捷栏 | 面板**外**独立 dock | 塞在面板里 |
| 合成区位置 | 右列（2×2）/ 上方（3×3） | 右列固定 |
| 分类入口 | 左轨直选 | 先点"创造"再点分类（两级） |
| 面板宽 | 固定 568px（口袋模式） | 880px |
| 标题 | 无标题栏，只有两颗键 | "背包"大字 + X |

## 6. 重构方案（v2）

保留已有的点击语义（`inventory-click.ts` 那 66 条断言不动），**只换外壳**：

1. **配色改成原版灰**：面板 `#c6c6c6`、槽位 `#8b8b8b`、字 `#3a3a3a`、直角 + 斜角边框。
2. **左右两条竖轨**：左轨 5 颗配方分类 + 底部物品栏；右轨 2~3 颗模式键。
3. **快捷栏移出面板**：底部独立 dock（`inv-hotbar-dock` 的对应物）。
4. **分类从两级变一级**：左轨点分类 = 直接进创造/配方网格，不再有"创造"大按钮。
5. **合成区随模式走**：2×2 在右列、3×3 在上方。
